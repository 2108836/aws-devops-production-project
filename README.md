# AWS DevOps Production Deployment

## Project Overview

This project demonstrates how a small Python web application can be deployed and managed using modern Cloud and DevOps practices.

The goal is to build a repeatable AWS deployment using Infrastructure as Code, containerisation, CI/CD automation, monitoring, and secure cloud configuration.

This project is being developed as a production-style portfolio project to demonstrate practical Cloud and DevOps engineering skills.

## Planned Technologies

- AWS
- Terraform
- Docker
- Git and GitHub
- GitHub Actions
- Python
- Linux
- Prometheus
- Grafana
